Why Budojo has no sub-processors

A sub-processor processes personal data for a processor (GDPR Art. 28). Budojo is not a processor of the academy's data: the app runs on the academy's own devices, and Budojo receives none of the data. So Budojo has no sub-processors.

The app still contacts a few third parties. Each is a service of the academy's own, or a public endpoint; none of them works for Budojo.

Third parties the app contacts

Who When What it sees Whose relationship
Google (Drive, sign-in) Only if the academy connects its Google account: the PC's backup copy, every 6 hours while the app is open; the sync between PC and phone; signing in on the phone. The backup archives: a database that is mostly plain text, and the encrypted documents. The sync files, sealed under the academy's sync key. The keys, in the account's hidden application data. Scopes drive.file and drive.appdata. The academy's own Google account, under the academy's agreement with Google.
GitHub The PC checks GitHub Releases for a new version and downloads it from there. The phone asks GitHub's API for the latest releases, to show an update notice. The device's IP address and user agent. No academy data. The public page where Budojo publishes its releases.
Sites behind the links the owner opens (YouTube, WhatsApp…) Only when the owner clicks a technique's video link or a WhatsApp button. The link opens in the device's browser or app; the app fetches nothing from these sites by itself. What any visit shows them. A WhatsApp link also carries the phone number or the message it opens. The owner's own browser and accounts.

A backup folder the owner chooses is written like any other folder. If a cloud service syncs it, that service is the academy's own choice too.

What is not there

  • No Budojo server, hosting or CDN.
  • No email provider: the app sends no email.
  • No push service: the phone's reminders are local notifications.
  • No analytics, error tracking or crash reporting.

Earlier versions of this page listed Cloudflare, DigitalOcean and Laravel Forge. They ran the hosted version of Budojo, which has been shut down.

Change process

If a version of the app starts contacting a new third party, this page and its source change in the same release.
