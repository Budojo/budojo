# v2.28.1 — 2026-05-21

Patch release: three small audit-log polish fixes following the v2.28.0 reviewer pass + a security dependency bump.

## 🕒 Audit page — three quiet fixes

- The `→` separator between actor and subject in each row was being read aloud by screen readers as "right-pointing arrow", adding noise to the row narration. It is now marked decorative — VoiceOver / NVDA skip it cleanly.
- The `?page=0` / `?page=-1` query strings used to silently fall back to page 1; they now return a `422` like every other invalid pagination value, matching what the API spec already documented.
- A rapid double-tap on **Applica** (or a page change landing while the previous request was still in flight) could briefly flash a stale row count before the fresh response landed. The list now cancels the previous request at the moment a new one fires — only the latest filter ever wins.

## 🔐 Two-factor library bumped to v9

`pragmarx/google2fa` 8 → 9. Same APIs as before, no user-visible change — pulls in upstream's latest fixes and PHP 8.4 polish.
