# v2.45.0 — You can see the update happening

## ⬇️ A new version no longer arrives out of nowhere

Budojo downloads new versions quietly in the background. Until now the only sign of it was a single notification once the download had already finished — easy to miss, and gone in a few seconds.

Now a thin line at the top of the app tells you what is going on: **which version is downloading and how far along it is**, and then that it is ready and will install when you next close Budojo.

It appears only when there is something to say. The rest of the time it is not there at all, and it never asks you to stop what you are doing — closing the app at the end of the day is still all it takes.

## 🔢 The app finally tells you which version it is

The version at the bottom of the **More** page always read `dev`, in every version we have ever released. It now shows the real one.

Worth knowing if you have ever tried to check whether an update actually installed: that number was never a reliable answer. From this release on, it is.
