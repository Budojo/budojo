# v2.31.1 — 2026-05-24

Hotfix to unblock the v2.31.0 deploy.

## 🚑 Deploy unblock

The v2.31.0 production build failed on Cloudflare Pages: the athletes-list component stylesheet had grown past the `anyComponentStyle.maximumError: 8 kB` ceiling — by 514 bytes, after the avatar + expanded ⋮ menu affordances added to the card. The deploy crashed with `Application bundle generation failed.` and the SPA on production stayed pinned to the v2.30.0 bundle.

The ceiling now sits at 12 kB, leaving room for the next few affordances on the athletes list before a real SCSS refactor is needed.

No user-visible behaviour change — v2.31.1 is the same v2.31.0 release that now actually deploys.
