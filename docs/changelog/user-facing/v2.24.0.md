# v2.24.0 — 2026-05-20

Two follow-ups based on owner feedback after the M9 release. The "1 documento da controllare" dashboard widget now also counts athletes who don't have a medical certificate on file at all — same CONI/insurance risk as an expired one. The dashboard page headers are also standardised: every page now uses a tight one-row "title · count chip · action" pattern instead of the mix of big H1 + stacked CTA that some pages had.

## 🩺 Athletes with no medical certificate flagged in the dashboard widget

Before: the widget on the athletes list counted only documents that were expired or expiring within 30 days. If an athlete had **no medical certificate at all**, they were invisible — same CONI/insurance liability, zero alert.

Now the widget counts both. A single combined "X atleti da controllare" header with a breakdown line `Y in scadenza · Z senza certificato`, so the owner sees at a glance both what's expiring soon and who's missing the cert entirely.

Rules:
- An athlete with status **active** counts; suspended / inactive don't (they can't train anyway).
- A soft-deleted certificate counts as "missing" — the row is no longer live.
- An athlete with an **expired** cert is already in the "scadenza" count, NOT double-counted.

## 🧭 One-row, tight page headers across the dashboard

Some dashboard pages used a big H1 + standalone CTA below it (~120 px of vertical space just for the header). Others — like the athletes list — already had a compact one-row pattern. All five most-visited dashboard pages now use the same one-row pattern:

- Feed
- Atleti
- Documenti in scadenza
- Presenze del giorno
- Riepilogo presenze mensile

Each header now reads `Title · count chip · primary action` on one row, dropping ~60–80 px of vertical space per page. The eyebrow (e.g. "PRESENZE") stays where it was already in use. The remaining dashboard pages (Impostazioni, dettaglio atleta, accademia, statistiche, ecc.) will follow in a subsequent release.
