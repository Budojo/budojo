# v2.22.1 — 2026-05-20

Build-budget patch unblocking the v2.22.0 SPA deploy. Same user-facing surface as v2.22.0 — every feature listed in those notes is now actually reachable on `https://budojo.it`.

## 🛠️ Internal: SPA initial-bundle budget raised to 1.25 MB

v2.22.0 introduced the M9 social-profile epic (athlete public profile page, sidebar split, `@handle` mention rendering) plus the per-response RSVP counter. Combined, the new code pushed the Angular initial chunk over the 1 MB Cloudflare Pages cap by 988 bytes — the build failed silently and the SPA stayed on v2.21.0 while the API was already on v2.22.0.

This patch raises the `maximumError` budget to 1.25 MB so the existing 500 kB warning still fires when the bundle grows, but the build no longer fails until we're meaningfully over the limit. A follow-up issue audits the initial chunk for lazy-load candidates (PrimeNG modules, BeltBadge usage in eager-loaded user-flair, etc.).
