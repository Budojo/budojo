# v2.27.0 — 2026-05-21

Two fronts: invisible "audit log" foundation that lets us answer "who deleted what, when" troubleshooting questions starting from the next release, and two more dashboard pages joining the uniform header pattern.

## 🔒 Audit log foundation — invisible today, indispensable tomorrow

Closes a real gap: there was no audit trail across the academy. If an athlete was deleted by mistake — or maliciously, in the future multi-user world — nothing recorded who did it. GDPR Art. 5 §2 (accountability principle) plus ordinary "who deleted Mario's payment last Tuesday" troubleshooting both demand an immutable log.

This release ships the foundation only — schema + write API + tests. The next release wires it up to the actual lifecycle events (delete, edit, upload) via observers and exposes the "Activity" page on `/dashboard/academy/activity`. So no user-visible change today; the rails go down first, the train rides them next.

## 🧭 Page-header pattern — two more pages join

`/dashboard/support` and `/dashboard/stats` now use the same shared header chrome as the rest of the dashboard pages — single visual rhythm across the app. Continuation of v2.24.0 + v2.26.0 waves.

Deliberately NOT migrated this release: `/help` + `/whats-new` (public routes, distinctive brand-glyph design); `/dashboard/athletes/:id` (complex composite header — will get its own focused PR).
