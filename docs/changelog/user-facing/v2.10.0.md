# v2.10.0 — 2026-05-13

Two feature drops and one production fix, all driven by ideas you sent back after v2.9.0 shipped.

## ✨ Reactions list — see who reacted with what

When a post on the community feed has 👏 claps and 🙏 prays, the count next to each button tells you how many — but not **who**. Tap the count line under the post and a sheet slides up listing every reactor with their name, handle, and belt, plus the emoji they picked. Tabs at the top let you filter to just 👏 or just 🙏. On phones it lands as a bottom-sheet you can flick down to dismiss; on desktop it opens as a centered dialog.

Reported by you as "voglio vedere chi ha messo cosa come Facebook".

## ✨ Promotion history per athlete

Every belt change AND every stripe change now records a dated row in the athlete's profile. Open an athlete → Promotions tab and you see the full ladder: "White → Blue · 2025-09-14", "Blue 0 → 1 stripes · 2026-02-03", "Blue 3 → 4 stripes · 2026-04-21", all the way back to the first row. Each entry shows who recorded the change.

Reported by you as "vorrei che per ogni atleta ci si ricordasse di questi passaggi (giorno per lo meno) nella sezione profilo... cosi io owner ricordo quando ho dato la striscia a chi".

## ✨ Stripe promotions also post to the feed

Until now, only **belt** changes auto-posted a celebration to the community feed. Stripe bumps were silent. Now a stripe increase fires its own feed post — separate from the belt-promotion post-type so the celebration text reads differently ("X earned their Nth stripe on the Y belt" vs. "X earned a new belt"). Stripe drops (4 → 0 when a belt goes up) deliberately don't celebrate — the existing belt-promotion post already covers it.

Reported by you as "vorrei mettere gli aggiornamenti/promozione di cintura nuova anche per le striscette".

## 🐛 Sidebar version on production

The version label in the sidebar read "Dev" instead of "v2.9.0" on budojo.it production. Cloudflare Pages clones the repo with depth=1 by default, which made `git describe` blind to the release tag and fall back to the dev placeholder. Fixed by unshallowing the clone in the build step — the sidebar now shows the real version on every deploy.
