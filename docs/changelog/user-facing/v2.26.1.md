# v2.26.1 — 2026-05-21

Patch release: a smaller register / reset-password / change-password page (the password-strength meter is no longer eagerly bundled) plus the last two test-coverage gaps from the #588 umbrella closed.

## ⚡ Smaller register / reset / change-password pages

The password-strength meter shipped its zxcvbn-ts analyser + ~700 kB of dictionaries on every page mount, even before the user typed a single character. Now the library is dynamic-imported on the first non-empty keystroke and cached after that, so a user who lands on `/auth/register` but never focuses the password field never downloads it.

No visible UX change for users who DO type: the meter still appears within ~10 ms of the first character. Stale-keystroke guard so a slow first-load doesn't overwrite a newer score.

## 🧪 Internal: closed two test-coverage gaps

`OnboardingChecklistComponent` and `ProfileApiTokensComponent` were the last two on the #588 untested-components list. New Vitest specs cover the visibility gate, the step-CTA + confirm-popup flows, and the create-then-plaintext + revoke flows.
