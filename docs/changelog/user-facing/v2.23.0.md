# v2.23.0 — 2026-05-20

Discoverability follow-up to the M9 social-profile epic. The athlete public profile shipped in v2.22.0 but reaching it from the feed or the athletes list took more taps than it should — both surfaces now have a direct tap target. Plus a small naming polish on the settings page header.

## 👆 Tap the author flair in the feed to open the profile

Every feed post and every comment renders an author flair: `Mario Rossi · @mariobjj · 🟦 Blue`. Until now it was just text — the only way to reach the author's profile was to scroll the body for an `@handle` mention or guess the URL. The whole flair (avatar + name + @handle + belt) is now tappable: one tap opens the author's public profile.

The link is **role-aware** — if you're an owner, you go to `/dashboard/u/<handle>`; if you're an athlete, to `/dashboard/me/u/<handle>`. Either way, you land on the same profile page, in the shell you're allowed to see. Only authors with a handle set get the tap target — until then the flair stays as plain text.

## 👤 "View public profile" icon on the athletes list

Each athlete row in `/dashboard/athletes` now carries a small id-card icon at the right edge, sitting before the existing pencil + trash buttons. Tap it to open that athlete's public profile in one step — no need to drill into the athlete detail page first.

The icon shows only on athlete rows whose linked user has a handle. Rows where the athlete hasn't been linked to a user (or the user hasn't set a handle yet) keep the original tap-to-detail behavior with no extra clutter.

## 🛠️ "Impostazioni" — settings page title aligned with the sidebar

The sidebar voice was renamed to "Impostazioni" in v2.22.0, but the page header at `/dashboard/profile` was still showing "Profilo" with the old subtitle. Fixed: the header now reads **"Impostazioni"** with a subtitle that lists the four tabs (Account, Sicurezza, Notifiche, Account-azioni). The inner "Profilo" tab stays — it's the account-info sub-tab of the settings group, unambiguous in context.
