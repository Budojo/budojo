# v2.43.0 — Budojo keeps itself up to date

## 🔄 No more checking for new versions

Until now, a new version of Budojo only reached you if you happened to visit the downloads page and install it by hand. From this release on, the app does it for you: it checks for updates shortly after you open it, downloads a new version quietly in the background, and installs it **the next time you close Budojo**.

Nothing is ever installed while you are working — no dialog in the middle of a check-in, no "restart now?". A notification simply tells you a new version is waiting; closing the app at the end of the day applies it.

**This is the one version you still install by hand.** From here on it takes care of itself.

*(If you use the portable version, it cannot replace its own file while running, so it stays a manual download — one more reason to prefer the installer.)*

## 🪟 It looks like an app now, not a website in a frame

Several things that gave away its origins are gone:

- **It opens on the sign-in screen.** Before, it opened on the public marketing page — "start free", "no credit card", a picture of a phone — inside an app you had already installed.
- **No more File / Edit / View menu bar.** That belongs to a text editor; nothing in it was useful here.
- **The window is the right colour.** The background was a dark blue that fought the app's light theme and made text hard to read. It now matches the app.
- **A tidier window frame**, with the usual minimise / maximise / close buttons where you expect them.
