# v2.28.0 — 2026-05-21

The "Attività" page is here. Every meaningful action across the academy — athletes added or removed, payments edited, documents uploaded, belts promoted, academy details changed — is now recorded as it happens and surfaced on a new owner-only page with filters.

## 🕒 Activity log — "who did what, when"

New sidebar voice **Attività** (between Statistiche and Community) opens the academy's activity log. One row per recorded action: actor, action verb, subject ("Mario Rossi", "May 2026 payment", "medical-cert.pdf"), timestamp.

Filters: action verb (e.g. `athlete.deleted`), date range. Paginated 20 per page.

Every write across the academy is recorded automatically:

- `athlete.created` / `athlete.updated` / `athlete.belt.promoted` / `athlete.deleted`
- `payment.created` / `payment.updated` / `payment.deleted`
- `document.uploaded` / `document.deleted`
- `academy.updated` / `academy.logo.replaced`

The log is **immutable** — owners can read it but never edit or delete entries. PII is redacted at write time: email and phone become opaque hashes (you can see that the value CHANGED without seeing what it was), fiscal codes are masked to the last 4 chars, and freeform notes / addresses are replaced with a `<redacted>` placeholder.
