# v2.42.1 — Security update

A maintenance release. Nothing changes in how you use Budojo — everything is where you left it.

## 🔒 Security fixes in the underlying components

Budojo is built on open-source components (the Angular framework it renders with, the Laravel framework the local server runs on, and the libraries they depend on). Security fixes were published for several of them, including one rated **high severity** that affected how text is displayed on screen.

This release picks all of them up. There is nothing for you to do beyond installing the update — no data change, no setting to review, no visible difference.

If you're running the desktop app, download the new installer from the releases page and run it over your current version. Your data stays exactly where it is.
