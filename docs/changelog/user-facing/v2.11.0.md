# v2.11.0 — 2026-05-13

A mobile-first overhaul. Six list-heavy pages now render as Apple-minimalist cards on phones instead of horizontally-scrolling tables, the sidebar drawer gets the standard Android gestures, the two profile dialogs fit phone viewports correctly, and the Android APK splash background flips dark to match the icon.

## ✨ Six lists turn into cards on phone

Below 768px (any phone in portrait) the tables that used to scroll sideways now render as cards, one row per item. Same information, but the thumb scrolls vertically — no more "fugge via a destra".

- **Athletes** (`/dashboard/athletes`) — Apple-style cards: name+age primary, belt + status + paid chips on a row, 3-dot menu for Edit/Delete. Tap the card → athlete detail.
- **Daily attendance** — one card per athlete, whole-card tap toggles "present today" (same handler as the desktop row, keyboard equivalent on Enter/Space).
- **Monthly summary** — one card per athlete, count + percentage right-aligned.
- **Athlete documents tab** — type primary with download / delete on the header, filename in the middle, expiry / cancelled status badge at the bottom.
- **Athlete payments tab** — one card per month, Paid / Unpaid tag + amount + paid-on date, mark / unmark icon button on the right.
- **Expiring documents** — athlete name linked (tap → that athlete's documents tab) + download affordance, expiry status badge at the bottom.

Desktop layout (≥ 768px) is unchanged.

## ✨ Sidebar drawer — native gestures

Three changes to the mobile sidebar:

- **Swipe-left to dismiss** — drag the open drawer to the left and it snaps closed. Standard Android nav-drawer pattern; finally lands here too.
- **No more page scroll bleed-through** — when the drawer is open and you drag inside it, the page underneath no longer scrolls along (iOS Safari + Chrome Android default behaviour, now suppressed).
- **No more drawer rubber-band** — the up/down bounce when you dragged inside the drawer past its scroll bounds is gone.

## ✨ Profile dialogs — correct fit on phone

The "Two-factor authentication" and "API tokens" dialogs on `/dashboard/profile` now size correctly below 768px (92vw with proper padding) instead of overflowing past the viewport edges.

## 🐛 Android APK splash

For users who installed the APK from the Play Store: the splash screen background now matches the icon's dark fill (`#0A0A0B`) instead of the previous white that put a jarring black square in the middle of a bright screen. Requires a Bubblewrap rebuild + reinstall to see — this is a TWA configuration change, not SPA code.
