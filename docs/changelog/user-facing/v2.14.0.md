# v2.14.0 — 2026-05-14

Push notifications are now fully connected end-to-end, the athletes list gains an undo for accidental deletes, mobile filters get a proper bottom-sheet, and the offline experience stops handing the user Chrome's error page.

## 🔔 Push notifications: now actually deliver and deep-link

The Browser notifications panel shipped in v2.13.0 was the user-side opt-in. v2.14.0 closes the loop:

- **Three notification types now fire a browser push** (in addition to the in-app inbox): a reply on a community post you commented on, an athlete in your academy earning a new belt, and a new event posted to the academy feed. The same opt-out gates from `/dashboard/profile → Notifications` still apply — one switch turns OFF both the inbox row AND the push.
- **Tapping the push deep-links to the post.** Click the OS notification → the SPA opens (or focuses an existing tab) on `/dashboard/me/feed#post-{id}`. No more "where was that?" moment after the chime.
- **Foreground messages get an in-app toast.** If a push arrives while you have a Budojo tab open, the OS doesn't pop a system notification (browser convention); we surface a PrimeNG toast instead so the signal isn't lost.

## ↩️ Restore a deleted athlete

A new "Cancellati" / "Deleted" filter on `/dashboard/athletes` shows the athletes you've previously deleted, with a one-tap Restore button per row. The athlete + their payment / attendance / promotion history comes back exactly as before.

The delete confirm now also warns prominently that **documents are deleted permanently** and can't be restored — that's still the policy from v1.0 (the file is wiped from disk on delete), but the warning makes the trade-off obvious before you tap Delete.

## 🎛️ Mobile filter cluster: bottom-sheet

On phone widths, the three filter dropdowns on the athletes list (Belt / Status / Paid) collapse into a "Filtri" chip with a badge showing how many are active. Tap the chip → a sheet slides up from the bottom with the dropdowns inside + Apply / Reset CTAs. Recovers about 80 pixels of vertical space for the actual roster.

Desktop layout (≥ 768px) is unchanged.

## 📶 Offline experience: less Chrome, more Budojo

If your network drops while you're inside Budojo:

- You land on our `/offline` page (with a Retry button) instead of Chrome's "ERR_CONNECTION_ABORTED" white page.
- When connectivity comes back, the SPA auto-redirects to wherever you were trying to go.
- A handful of frequently-read endpoints (athletes list, your academy, the community feed) keep a 1-hour cache so a flaky connection gives you stale-but-recent data instead of a hard failure.

The offline plumbing existed since v1.20; what was missing was the service worker configuration to actually route around `/api` calls correctly. Now they do.
