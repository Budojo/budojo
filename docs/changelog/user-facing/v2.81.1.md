# v2.81.1 — L'APK per Android arriva con ogni versione

Nell'app non cambia niente. Cambia come viene preparata la versione per il telefono.

## Telefono

- **L'APK per Android è allegato a ogni versione.** La v2.81.0 era uscita senza, perché il controllo che la prova sull'emulatore si bloccava: l'APK è stato aggiunto dopo. Ora il controllo funziona anche quando la versione precedente protegge le chiavi dell'accademia, e l'APK arriva insieme all'installer per il PC.
