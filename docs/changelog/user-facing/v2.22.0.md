# v2.22.0 — 2026-05-20

Athletes in your academy now have a public profile page. The card shows first name, current belt, joined date, and the full promotions timeline — the same view your peers see when they tap your name. Composers can tag `@handle` in feed posts and comments to drop a clickable link to that profile. The sidebar is reorganised so "Profilo" (which was actually settings) becomes "Impostazioni" and a new "Il mio profilo" voice opens your own public profile in one tap.

## 👤 Athlete public profile page

Tap an athlete's name in the feed or in the sidebar's new "Il mio profilo" voice to land on `/dashboard/u/<handle>`. The page shows:

- Avatar + first name + `@handle`.
- Current belt with stripes badge.
- "Joined {month year}" line.
- The full promotions timeline (newest first, up to 50 events) — every belt change and every stripe promotion with the recorded date.

The page is **visible to your same-academy peers by default**. If you don't want it visible, the upcoming Settings → Privacy toggle (next release) flips it off. Even when visible, the page is **never exposed cross-academy** — someone from a different academy who guesses your handle sees the generic "Profile not available" state, not a leak that the handle exists.

## 🏷️ `@handle` tagging in feed posts + comments

When you write a community post or a comment, typing `@mariobjj` (any valid handle) automatically renders as a tappable link that opens the public profile. Same pattern as Facebook / Twitter / Mastodon. Mentions in plain prose work too — write naturally, the SPA picks up valid handles and leaves email-looking text alone.

Today the link is rendered passively (you write the handle, it becomes a link). A composer-side autocomplete (typing `@` opens a picker on academy athletes) is queued for the next release.

## 🧭 Sidebar — "Profilo" → "Impostazioni" + new "Il mio profilo"

The sidebar voice "Profilo" actually opened settings (notifications, password, sessions, API tokens). With the new public-profile concept, that name collided. We renamed it:

- **Impostazioni** (cog icon) — your real settings. Route unchanged.
- **Il mio profilo** (id-card icon) — opens your own public profile so you see the same view your peers see. Hidden when your handle is still empty; set one in the profile page to surface the row.

## 🟢 RSVP counter on event posts — Going + Maybe each get their own number

A user with a Pixel 8 Pro reported that the RSVP counter on event posts only ever showed a number next to "Ci sarò" (Going), never next to "Forse" (Maybe). The aggregate count was being rendered against the first chip; flipping your response to Maybe wiped the badge entirely.

The feed now ships **per-response counts** — Going renders its own number, Maybe renders its own number, both update optimistically when you tap. The total still adds up: `going_rsvps_count + maybe_rsvps_count == rsvps_count`.

## 🏗️ "Train here too?" step in academy setup

When you set up a new academy as the owner, the wizard now asks one final question before submit: do you train at this academy as an athlete too, or only manage it? Picking "yes" automatically creates your athlete row so your own attendance and promotions are tracked from day one — no follow-up "invite yourself" flow needed.

## 🔐 Server-side role gate on owner-only routes

Before this release, the SPA hid owner-only screens from athletes (no buttons, no menu items), but the API itself didn't re-check the role on every endpoint — meaning a direct `curl` from an athlete's token could in theory reach owner-only data. The server now re-checks the role on every gated route; the SPA gates are now defense-in-depth, not the only gate.

## 🔔 Notification preferences — 3 collapsible groups

The notifications page previously listed 14+ toggles in one flat column. They're now grouped into three collapsible sections: **Owner**, **Athlete**, **Community**. Opens with the section relevant to your role expanded; the rest collapse, so the page is one scroll-page on a phone.

## 🗓️ Attendance page — today-aware title + no-class banner

If you visit the attendance page on a day with no scheduled training, the page no longer renders a "Check-in di oggi" header with an arbitrary other date — it now says clearly "Nessun allenamento oggi" with the next training day's date instead. The athletes list still shows tonight's attendees when there IS a class, with the right session date in the title.
