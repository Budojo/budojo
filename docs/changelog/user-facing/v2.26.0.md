# v2.26.0 — 2026-05-21

The biggest user-visible addition is the **attendance percentage chart** on each athlete's profile + the athlete's own `/me/attendance` page — the chart you asked for the day before. Alongside it, three Honor-200-reported bug fixes and a small bundle-size audit win.

## 📈 "% di presenze" chart su profilo atleta e /me

Each athlete detail Attendance tab now opens with a 90-day attendance summary:

- **Donut** with the headline rate (`75%`) dead-centre.
- **Bar timeline** below, one bar per realized lesson day, colour-encoded — primary indigo = atleta presente, muted = assente. Trends jump out at a glance.
- **Range switcher** 30 / 90 / 365 days — default 90.
- **Empty state** when there are no lessons in the window (`expected_count === 0`) — no misleading `0%`.

The same chart lands on `/me/attendance` for athletes looking at their own progress. The denominator is "realized lesson days" — distinct dates where the academy actually held a session AND the athlete was already on the roster — so closures, holidays and pre-roster days never penalize the rate.

## 🛠️ Sidebar footer + "Impostazioni" parity per atleti

After v2.25.0 the athlete sidebar showed only a bare Sign-out — no language toggle, no version label, no Help / Privacy links. Reported via @eli1982 on Honor 200. Now both sidebars (owner + atleta) carry the same footer: lang toggle, Help · Privacy · vX.Y.Z.

Same report: the athlete settings page title still read "Il tuo profilo" while the sidebar voice that opens it is "Impostazioni" (renamed for the owner in v2.23.0). Page header now reads "Impostazioni" / "Settings" — matching how the user navigated to it.

## 🎯 Reaction chip — bordo destro non più tagliato su Honor 200

Honor 200 webview (EMUI/MagicOS) wasn't clipping the active reaction chip's right corner, leaving the count badge hanging outside the pill. Fixed via per-corner border-radius on the chip children + `overflow: clip` + `isolation: isolate` belt-and-suspenders. Inner seam stays flush; outer corners stay round on every webview.
