# v2.42.2 — Expiry reminders actually work now

## 🔔 The medical-certificate reminders were never firing

Budojo is supposed to warn you when an athlete's medical certificate is about to expire, with a desktop notification. On the desktop app that check ran every few minutes and **failed silently every single time** — it could not open your database, gave up, and left no sign of it anywhere you would look.

That means: since the desktop app launched, **you have not been getting expiry reminders**. Not "they were late" — they never ran.

This release fixes it. The reminders now run as intended, and the same fix covers the other background jobs (the unpaid-athletes digest, the attendance-streak notices, the routine clean-up tasks), which were failing for the same reason.

**Worth doing once after updating:** open **Athletes** and check the expiring-documents widget on your dashboard directly, in case something slipped past while the reminders were silent.
